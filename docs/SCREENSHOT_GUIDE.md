# 캡처 안내

아래 화면을 주소창과 결과가 함께 보이도록 캡처하여 이 폴더에 저장한다.

1. `01-docker-engine.png`: Docker Desktop에서 **Engine running** 상태.
2. `02-terminal-docker-check.png`: 터미널의 `docker --version`, `docker info`, `hello-world` 성공 출력.
3. `03-port-8080.png`: 브라우저 주소창의 `http://127.0.0.1:8080`과 웹 페이지.
4. `04-port-8081.png`: 브라우저 주소창의 `http://127.0.0.1:8081`과 웹 페이지.
5. `05-bind-mount.png`: 바인드 마운트 반영 뒤 변경된 문구가 보이는 `http://127.0.0.1:8080`.
6. `06-volume-persistence.png`: `docker exec codyssey-volume-check-2 cat /data/proof.txt`의 `volume-data-survives-container-recreation` 출력.
7. `07-github-repository.png`: 공개 GitHub 저장소의 `main` 브랜치와 파일 목록이 보이는 화면(토큰·비밀번호는 보이지 않게).

Windows에서는 `Win + Shift + S`로 캡처 후 그림판 등에 붙여넣고 위 파일명으로 저장한다. 민감정보와 개인 경로는 가린다.
